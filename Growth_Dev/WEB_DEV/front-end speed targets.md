### 🧱 HTML Checklist (W3Schools HTML Tutorial)

- [ ] **HTML Forms Module:** (Forms, Attributes, Elements, Input Types). _Checkpoint:_ You can code a login or signup form completely from scratch in your `file.html`.
    
- [ ] **HTML Id & Class:** _Checkpoint:_ You can successfully target specific elements versus groups of elements before you open your CSS file.
    

### 🎨 CSS Checklist (W3Schools CSS Tutorial)

- [ ] **The Box Model Basics:** (Syntax, Selectors, Margins, Padding, Height/Width, Box Sizing). _Checkpoint:_ You can control the exact spacing of an element without it breaking the layout.
    
- [ ] **CSS Display & Position:** (Specifically `display: block/inline/none` and `position: absolute/relative/fixed`). _Checkpoint:_ You can pin a navigation bar to the top of the viewport.
    
- [ ] **CSS Flexbox & CSS Grid Modules:** _Checkpoint:_ You can build a multi-column layout without using outdated floats.
    
- [ ] **CSS Responsive Module:** (Specifically Media Queries). _Checkpoint:_ Your layout cleanly snaps from 3 columns down to 1 column when resizing the browser window.
    

### 🧠 JavaScript Checklist (W3Schools JS Tutorial)

- [ ] **JS Fundamentals:** (Variables, Operators, If Conditions, Loops, Functions, Objects, Arrays). _Checkpoint:_ You can manipulate data structures and run basic conditional logic in your `file.js`.
    
- [ ] **JS HTML DOM & Events Modules:** _Checkpoint:_ You can use `document.querySelector` and `addEventListener` to trigger a style change (like a dark mode toggle) when a button is clicked.
    
- [ ] **JS Advanced -> Asynchronous & JSON:** _Checkpoint:_ You can write an `async/await` fetch function to pull data from an API, parse the JSON, and render it dynamically on your HTML page.
    

### 🛠️ The "Lock-In" Protocol

To keep your fast pace, run this mental filter over every single page you click on W3Schools:

1. **Look at the code example.** 2. **Ask yourself:** _"Do I understand exactly what this is doing and why?"_
    
2. **If YES:** Skip it immediately. Move down the sidebar.
    
3. **If NO:** Open your Neovim, type it out manually in your per-chain test file, see it work, and then move on.
    

Once you hit that final JS Asynchronous checkmark, you are cleared to break out of the browser sandbox and start learning Python for the back-end.
